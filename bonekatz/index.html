Bonekatz Clip Scheduler

Prepare gaming clips, organize local publishing plans, and manage Twitch and YouTube stream titles from one desktop app.

Built for the BoneKatz channel owner's own workflow. This information site does not provide a public sign-up, download, or account connection.

Prepare clips

Keep a local queue of video files, captions, tags, cover images, playlist selections, and planned times. Optional AI tools draft copy from the writing context you supply.

Manage live metadata

Connect the intended accounts, select an existing YouTube broadcast and Twitch game category, review the text, then choose which platform to update.

Upload privately

Versions with YouTube Upload can send a selected clip, cover image, and metadata to YouTube as a private video and add it to a selected playlist.

What the connected accounts are used for

The app uses YouTube API Services to read the connected channel, playlists, upcoming or active broadcasts, and relevant video details. Editing access lets it change selected video metadata and, in upload-enabled versions, upload private videos, set covers, and add playlist entries.

Twitch access is used to identify the connected channel, find game categories, and update the channel's title, category, and tags. A Twitch go-live notification is a draft to copy into Twitch Stream Manager manually.

Google and Twitch handle sign-in and account consent in your browser. The app stores authorization tokens in the operating system credential vault.

Review before you apply changes

Saving a clip to the local calendar does not schedule or publish it on a platform. Live metadata changes require an Update action. The app does not start or stop streams. YouTube's separate game-title picker is handled in Studio.

Features depend on the installed version. The current StreamingPC build has Live Stream Manager and local clip planning. The newer GamingPC build also includes private YouTube uploads.
