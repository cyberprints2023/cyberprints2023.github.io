Terms of use

Terms for the channel owner's personal desktop workflow.

Purpose and access

Bonekatz Clip Scheduler is a personal tool for preparing gaming clips and managing the owner's connected channels. This website provides information; it does not offer a public hosted service or grant access to any channel.

Use the app only with accounts and content you are authorized to manage. Review the selected account, broadcast, files, metadata, and visibility before an update or upload. Keep copies of original media and protect your Windows account and credentials.

Connected services

The app uses YouTube API Services. By using its YouTube features, users agree to be bound by the YouTube Terms of Service. Connected Twitch and OpenAI features remain subject to those providers' applicable terms, limits, and charges. Optional OpenAI API generation may incur charges on the configured API account.

Read the privacy policy before connecting accounts. Authorization can expire or be revoked, and API availability or limits can affect a feature.

Feature limits

A local queue entry is not a platform publishing schedule. Upload-enabled versions request private YouTube uploads; platform checks and processing may require review in Studio. Live Stream Manager does not start or stop broadcasts and cannot apply Twitch go-live notification text through Twitch's public API.

AI-generated copy can be inaccurate. Review and edit it before sending it to a platform. The app does not promise audience growth, platform approval, or uninterrupted service.
