Shop connection

Etsy connection page is ready

Start the Etsy connection from the CyberPrintsStudio program on your Windows PC. This page will open after you approve access on Etsy.

  1. Copy the connection response using the button below.
  2. Return to the CyberPrintsStudio Command Prompt window.
  3. Paste it when the program asks, then press Enter.

Paste this only into the CyberPrintsStudio program on your PC. Do not post it in chat or add it to GitHub.

Copy manually if the button does not work

The connection is finished only when the Windows program reports ETSY CONNECTED. You can then close this tab.

This page helps connect your own Etsy shop. It does not create or publish listings.
